Catálogos de software libre

Para buscar programas libres que no aparecen en esta guía pueden consultarse estos catálogos:

  • Free Software Directory. Lo mantiene la Free Software Foundation y solo recoge programas con licencia libre. Está en inglés.
  • F-Droid. Es la tienda de aplicaciones libres para Android, y en «Herramientas para Android» se explica cómo usarla.
  • Flathub. Reúne las aplicaciones para GNU/Linux, está en castellano e indica en cada programa si es libre o privativo.
  • Wikipedia. Clasifica el software libre por tipo, y tiene categorías para las aplicaciones de Android y para los programas de seguridad.

Para encontrar una alternativa libre a un programa concreto puede usarse AlternativeTo, como se explica en «Herramientas libres».
